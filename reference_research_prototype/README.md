# PABPC1–RNA reference preparation: research prototype

**This is an experimental reference-only notebook, not a validated production workflow.** It does not build the 61 variants, support RNA extension beyond 31 nt, handle chemical modifications, or calculate MM/GBSA. Do not use its PDBs to rank sequences or claim a validated binding pose without further expert review.

[Open the research prototype in Google Colab](https://colab.research.google.com/github/JaredSia/mmgbsa_H3/blob/main/reference_research_prototype/PABPC1_reference_research_prototype.ipynb)

Upload the revised input PDB into Colab. Source code is embedded; uploaded structures and sequence workbooks are **not** in this repository. Files are saved in a named Google Drive run directory. Completed stages and saved unfinished stages can be resumed when the input, code, seed and OpenMM version match; changes of runtime hardware may change numerical results. Do not run the same case concurrently. The notebook optionally installs official ChimeraX 1.12 after the user accepts its noncommercial license; that installer has not been tested on every Colab image.

The input has extreme overlap, so the experimental runner deliberately uses a nonphysical soft-repulsion ramp followed by vacuum and explicit-water physical-force-field minimization. It also uses a custom anti-inversion penalty; this is **not part of ff19SB/OL3**. Nonphysical forces may influence the path even when the stereochemistry penalty is zero at the end. Artificial and full-force-field energies are separately labeled. It checks expected stereochemical signs, RNA phosphodiester distances, <2 Å protein–RNA contacts, finite coordinates, conservative 1 Å backbone RMSD and 3 Å restrained-atom displacement review thresholds, and the recorded minimizer objective-gradient and constraint thresholds. These are chosen screening thresholds, not universal validation criteria. It refuses to advance from a physical stage when its reported thresholds are not observed or the stereochemical penalty remains active. Passing these limited checks does not establish an all-atom geometry, a biologically correct binding pose, equilibrium or affinity.

To implement the previously requested 5′-OH, the runner explicitly removes E37 atoms P, OP1 and OP2 from a **new copy** and logs them. A 3′-OH is assumed and checked after hydrogen addition. It removes the invalid input cell from that copy before generating a new box. Protein and other existing heavy atoms are checked for preservation during hydrogen addition. Protein sequence is checked against UniProt P11940.

Configuration: OpenMM ff19SB/OL3 and TIP3P with K+/Cl−, 1 nm rectangular padding on each side, and 0.089 M added KCl as a simplified proxy for the 89 mM potassium acetate in Müller. Magnesium acetate, glycerol and other buffer components are omitted. The model also has artificial charged protein termini. ff19SB was developed with OPC water. These are material limitations when comparing with assay conditions.

The optional ChimeraX smoke test makes independent A→G, A→C and A→U variants at E40 and verifies expected atom names, protein and RNA backbone coordinates, glycosidic attachment and standard force-field assignment. Its 25-step vacuum minimizations are **only smoke tests**, not converged variant simulations. If ChimeraX is absent it emits scripts only.

Local evidence: component tests passed; the actual revised input was tested in two dry initializations and a deliberately short solvent run. The short solvent run did not meet the requested gradient/constraint thresholds and is not a final result. An actual ChimeraX 1.12 G/C/U smoke test was run on that exploratory structure. Full stages, GPU operation, Colab installation, GPU/Colab interruption behavior beyond local checkpoint tests, independent structure validation, and modified nucleotide force fields remain unverified or unsupported.
